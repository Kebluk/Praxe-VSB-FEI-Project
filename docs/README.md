# Project

## Description
Uprostřed displeje se nachází hráč, který pomocí rotačního enkodéru otáčí výsečí na obrazovce, štítem. Ten jej chrání před kulkami lítající z náhodných stran v náhodných intervalech a s náhodnou rychlostí. Když však štítem mine má druhou šanci použít tlačítko v momentě, kdy by se jej kulka dotkla. Za správné načasování dostává bod, za špatné ztrácí jeden ze svých životů.
